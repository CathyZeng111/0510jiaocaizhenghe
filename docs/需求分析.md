# 需求分析

## 1. 知识点粒度如何定义

本系统将医学教材中的知识点粒度划分为“章节 / 小节 / 术语知识点”三层，而不是把整本教材直接切成无层级的扁平节点。第一层对应教材中的一级章节，例如“第一章 绪论”“第二章 细胞的基本功能”，在代码中以 `metadata.level = primary` 和 `node_type = primary` 表示，用于承载教学大纲的主干结构。第二层对应章节下面的小节或二级标题，例如“第一节 概述”“第二节 层次结构”，在代码中以 `metadata.level = secondary` 和 `node_type = secondary` 表示，用于保留教材原有叙述顺序和局部主题边界。第三层是术语知识点，例如“动作电位”“静息电位”“炎症反应”等，在代码中使用 `node_type = knowledge_point` 表示，用于支撑跨教材语义对齐、图谱合并和 RAG 检索。这样的粒度设计兼顾了教师理解和算法处理：章节层保证教学结构不丢，小节层保证展开阅读不乱，术语层则让系统可以识别不同教材中同一概念的不同表述。

## 2. 重复知识点如何判定

跨教材整合的核心问题是判断不同教材中的两个知识点是否指向同一概念。当前实现采用“名称规范化 + token Jaccard + 定义文本 Jaccard + embedding 语义相似度”的组合策略，并在 `backend/app/graph_integration.py` 中设置明确阈值：`MERGE_THRESHOLD = 0.72`，当综合相似度达到该阈值时，系统倾向于将多个节点合并为一个 canonical node；`WEAK_KEEP_THRESHOLD = 0.48`，当相似度处于弱相关区间时，系统不会冒进合并，而是在整合决策中给出 keep 理由，提示它存在相似概念但未达到合并条件。重复判定不是只看字符串完全一致，因为医学教材常出现中文、英文、缩写和不同译名混用，例如“白细胞”“white blood cell”“leukocyte”。因此系统先对名称做归一化和同义词替换，再结合定义文本和向量相似度共同判断，最终为每条 `merge / keep / remove` 决策记录 `score`、`confidence`、`affected_nodes` 和 `reason`，便于教师审查和通过对话修正。

## 3. 如何保证教学连贯性

教学连贯性主要通过图谱边类型和章节层级共同维护。单本教材知识图谱构建阶段会生成 `contains`、`prerequisite`、`parallel`、`applies_to` 等关系，其中 `prerequisite` 边用于表达学习先后依赖，例如理解“动作电位”前需要掌握“静息电位”，理解“免疫应答”前需要先理解“抗原”和“抗体”。在 LLM 抽取方案中，prompt 明确要求关系类型只能来自 `prerequisite / parallel / contains / applies_to`，并通过 few-shot 示例约束输出，例如“静息电位 prerequisite 动作电位”“动作电位 applies_to 兴奋-收缩耦联”。在本地启发式方案中，系统也会按章节顺序建立相邻章节之间的 prerequisite 关系，避免图谱只剩孤立节点。跨教材整合时，系统不会简单删除所有重复节点，而是优先保留一级章节、定义更完整和来源更多的节点，并重写边的 source/target，保证合并后图谱仍能表达“上位主题包含下位知识点”和“前置知识通向后续知识”的教学路径。

## 4. 为什么要求 30% 压缩比

跨教材整合不是把所有教材内容堆在一起，而是要把多本教材中重复、冗余、低价值的信息压缩成一份更适合教学使用的统一知识结构。当前实现用 `CHAR_BUDGET_RATIO = 0.30` 表示整合后保留内容总字数不超过原始总字数的 30%，并在 `enforce_char_budget()` 函数中执行预算控制。具体策略是先计算源图谱节点定义、别名和名称的总字符数，再按节点优先级排序：来源教材越多、层级越高、定义越完整、关系越多的节点越优先保留；低优先级、孤立、重复或定义价值较低的节点会被裁剪，并生成 `remove` 类型的整合决策，说明删除原因是满足 30% 字数预算。这个约束能逼迫系统完成真正的去重提纯，而不是只做可视化拼接。前端会展示原始总字数、整合后字数、预算上限和压缩比，教师可以清楚看到压缩是否达标，也可以通过聊天反馈要求保留某个被裁剪的关键节点。

## 5. RAG 分块策略选择依据

RAG 问答要求切片既不能过短导致上下文碎片化，也不能过长导致 top-5 片段塞入 LLM 后噪声过多。当前系统在演示优化后采用 `chunk_size = 800`、`chunk_overlap = 80` 的 sliding window 策略，并尽量在句号、问号、分号或换行附近切断。选择该粒度有三点理由：第一，医学教材中一个概念定义、机制解释或临床说明通常在数百字内可以完整表达，800 字能容纳一个较完整的局部知识单元；第二，500-800 字仍适合放入 LLM 上下文，top-5 chunk 不会让 prompt 过长；第三，80 字重叠可以降低“定义在上一块、解释在下一块”造成的截断风险。为提升速度，系统还跳过目录、版权、编委、前言、参考文献等低价值章节，并使用 fingerprint 复用 Chroma 索引，避免同一批教材反复向量化。
