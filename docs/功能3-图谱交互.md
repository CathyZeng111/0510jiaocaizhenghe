# 功能 3：知识图谱交互

## 交付范围

本次新增一个可复用 React 组件 `InteractiveGraph`，用于展示教材知识图谱。组件不依赖重型图谱库，交互基于原生 SVG 与 React 状态实现。

新增文件：

- `frontend/src/features/InteractiveGraph.tsx`
- `frontend/src/features/InteractiveGraph.css`
- `frontend/src/features/graphInteractionTypes.ts`

## 功能点

- 节点点击后在右侧展示详情，包括教材来源、出现频次、章节、关键词、说明和扩展元数据。
- 节点颜色按教材来源区分，支持通过 `sources[].color` 指定颜色；未指定时自动分配调色板。
- 节点大小按 `frequency` 映射，频次越高节点越大。
- 搜索框支持按节点名称、说明、章节、教材来源和关键词检索，命中节点以描边高亮，未命中节点淡化。
- SVG 画布支持滚轮缩放、拖拽平移、按钮放大/缩小/重置。
- 节点支持鼠标拖拽调整位置，若数据中提供 `x`/`y` 会作为初始位置。

## 数据结构

组件 props 使用 `KnowledgeGraphData`：

```ts
type KnowledgeGraphData = {
  nodes: KnowledgeGraphNode[];
  edges: KnowledgeGraphEdge[];
  sources?: TextbookSource[];
};
```

核心字段：

- `nodes[].id`：节点唯一标识。
- `nodes[].label`：节点展示名称。
- `nodes[].frequency`：出现频次，用于节点大小。
- `nodes[].sourceId`：教材来源 ID，用于颜色映射。
- `nodes[].x` / `nodes[].y`：可选初始坐标。
- `edges[].source` / `edges[].target`：边两端节点 ID。
- `sources[]`：教材来源列表，可包含自定义颜色。

## 使用示例

```tsx
import InteractiveGraph from "./features/InteractiveGraph";
import type { KnowledgeGraphData } from "./features/graphInteractionTypes";

const graphData: KnowledgeGraphData = {
  sources: [
    { id: "book-a", title: "教材 A", color: "#2f7dd3" },
    { id: "book-b", title: "教材 B", color: "#d95f43" },
  ],
  nodes: [
    {
      id: "n1",
      label: "梯度下降",
      frequency: 18,
      sourceId: "book-a",
      chapterTitle: "优化方法",
      keywords: ["优化", "机器学习"],
    },
    {
      id: "n2",
      label: "损失函数",
      frequency: 12,
      sourceId: "book-b",
    },
  ],
  edges: [{ source: "n1", target: "n2", label: "依赖", weight: 2 }],
};

export function GraphPanel() {
  return <InteractiveGraph data={graphData} height={640} />;
}
```

## 集成说明

当前任务要求不修改 `frontend/src/main.tsx`。后续集成时，只需要在目标页面导入组件与样式入口即可。`InteractiveGraph.tsx` 已自行导入 `InteractiveGraph.css`，调用方只需要传入符合类型的数据。

如果后端返回教材解析结果后再生成图谱，建议在适配层将后端字段转换为 `KnowledgeGraphData`，让组件保持纯展示与交互职责。
